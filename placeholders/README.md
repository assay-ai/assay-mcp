# Placeholder packages

These packages reserve npm names that look like `@assay-ai/mcp`: `assay-mcp`, `assay-ai-mcp`, `@assay/mcp` (folder `assay__mcp`) and `assaymcp`. Each one has no code, no dependencies and no scripts, and its README points to `@assay-ai/mcp`.

They are published by hand, once, by the npm organisation owner. The release workflow never publishes them.
