# Placeholder packages

These packages reserve npm names that look like `@goassay-ai/mcp`: `goassay-mcp`, `goassay-ai-mcp`, `@goassay/mcp` (folder `goassay__mcp`) and `goassaymcp`. The unscoped `assay-mcp` belongs to a third party (README, residual risk T11). Each one has no code, no dependencies and no scripts, and its README points to `@goassay-ai/mcp`.

They are published by hand, once, by the npm organisation owner. The release workflow never publishes them.
