# goassay-mcp

This package is a placeholder. It contains no code. It reserves the PyPI name for a future Python version of the Assay MCP proxy, so that nobody else can publish a look-alike.

Today the Assay MCP proxy is [`@goassay-ai/mcp`](https://www.npmjs.com/package/@goassay-ai/mcp) on npm. Install it with the exact command from the [assay-mcp README](https://github.com/assay-ai/assay-mcp#readme). To call Assay from Python, use the SDK: [`goassay`](https://pypi.org/project/goassay/).
